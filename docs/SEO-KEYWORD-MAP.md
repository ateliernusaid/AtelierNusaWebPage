## Linking rules

- Supporting articles should link to `/jasa-arsitek-lombok` using descriptive, natural anchor text.
- Location pages should link to the main service page and to the relevant cost or portfolio page.
- The main service page should link to location, service, process, portfolio, and cost pages.
- Avoid using the same primary keyword as the main heading on multiple location pages.
- Keep the homepage English. Create separate English landing pages if international search becomes a measured growth channel.

## Content priorities

1. Publish or update one useful long-tail page at a time, then link it into the cluster.
2. Add original project evidence, scope, location context, and practical cost guidance.
3. Review Search Console queries and CTR before changing titles again.
4. Do not add unverified reviews, ratings, guarantees, or project counts.

## Baseline

The current GA4 export recorded 197 Google organic sessions and 1 `lead_form_submit` during the available reporting period. Ranking work should therefore be measured together with qualified lead volume, not position alone.

# Brief Project Atelier Nusa Web

Berikut adalah ringkasan informasi dan "kredensial" (data akses/konfigurasi) terkait proyek website Atelier Nusa yang ada di environment ini:

## 1. Repositori & Version Control
*   **Git Remote (Origin):** `https://github.com/ateliernusaid/AtelierNusaWebPage.git`
*   **Branch Utama:** `main`
*   **Metode Update:** Commit dan push ke branch `main` akan otomatis memicu proses build dan deploy di Vercel.

## 2. Environment & Lokasi Lokal
*   **Direktori Proyek:** `d:\SCRIPT\YapAutoBot-NTE-main\AtelierNusaWeb`
*   **Framework:** HTML statis dengan Vite bundler.
*   **Build Command:** `npm run build` (menghasilkan folder `dist/`)

## 3. Deployment & Live URL
*   **Platform Hosting:** Vercel (terhubung langsung ke GitHub repository)
*   **Domain Utama:** `https://www.ateliernusa.id/`

## 4. Struktur Penting
*   **File Utama:** `index.html` (Homepage), `lahan.html`, `artikel.html`
*   **CSS Style:** Terpusat di folder `src/styles/` (contoh: `variables.css`, `home.css`, `base.css`)

*(Catatan: Website ini merupakan situs statis, sehingga tidak menggunakan database kredensial SQL atau file `.env` yang menyimpan API Keys secara lokal di direktori ini)*

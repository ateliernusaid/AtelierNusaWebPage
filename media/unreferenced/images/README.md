# Production Images

Use these folders for optimized, deployable media:

- `brand/` - logo and brand assets
- `projects/` - project media grouped by slug
- `articles/` - article and guide images
- `landing/` - future Indonesian Ads landing page media
- `og/` - social preview images
- `responsive/` - generated WebP variants used by the homepage `srcset` attributes

High-resolution originals belong in `media/source`, not in this deploy folder.
